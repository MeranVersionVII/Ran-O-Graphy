Modul 02 · Basic

Formula prompt P.K.T.F.C

  • Peranan — "Kau copywriter F&B 10 tahun"
  • Konteks — siapa audience, produk, matlamat
  • Tugas — apa sebenarnya yang perlu dibuat
  • Format — panjang, struktur, bahasa, emoji
  • Contoh — beri 1–2 contoh gaya yang kau suka
Peranan: Kau copywriter social media untuk bisnes kecil Malaysia. Konteks: Produk kami sambal bilis premium, audience ibu bekerja 25–40. Tugas: Tulis 3 caption Instagram untuk promo 11.11. Format: Bahasa santai, max 80 patah perkataan, 1 hook kuat di baris pertama, CTA di hujung. Contoh gaya: "Lauk tak sempat masak? Sambal ni selamatkan makan malam kau."

Rahsia sebenar: iterasi. Prompt pertama jarang sempurna — minta Claude perbaiki, ubah tone, atau beri 5 versi lain.

Modul 03 · Intermediate

Gambar & Visual

Claude jadi art director kau — dia rancang, tulis prompt, dan bina visual berasaskan design.

A

Prompt untuk AI gambar

Claude tulis prompt terperinci untuk tool penjana gambar (cth. Midjourney, Ideogram, Gemini, ChatGPT image).

B

Poster & infografik

Guna Artifacts untuk bina poster, quote card, infografik dalam HTML/SVG — tukar teks, saiz, warna terus.

C

Analisis visual

Upload gambar competitor / draf design — Claude beri komen layout, warna, dan cadangan penambahbaikan.

Nota jujur: Claude sendiri tak lukis gambar foto-realistik. Kekuatannya ialah idea, prompt, dan design berstruktur — gabungkan dengan tool gambar untuk hasil terbaik.

Posting Social Media

Carousel

Balas komen

Template balasan & soalan lazim (FAQ).

Modul 07 · Advance

Video

  • Skrip — hook 3 saat pertama, isi, CTA (Reels/TikTok/YouTube)
  • Storyboard — shot list, sudut kamera, B-roll, teks atas skrin
  • Prompt video AI — untuk tool seperti Veo, Kling, Runway
  • Subtitle & caption — transkrip, terjemah, potong klip
  • Advance: video template berasaskan code (cth. Remotion) dibina dengan Claude Code
Prompt: Tulis skrip TikTok 30 saat untuk produk kami. Format jadual: [Masa] | [Visual] | [Dialog] | [Teks skrin]. 0–3s mesti hook yang buat orang berhenti scroll. Akhiri dengan CTA "komen NAK". Beri juga 3 variasi hook untuk A/B test.
